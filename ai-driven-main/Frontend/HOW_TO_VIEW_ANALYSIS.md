# 🎯 How to View Analysis.jsx Layout with Dummy Data

## 🚀 **Quick Ways to View the Analysis Page:**

### **Method 1: Using the Demo Button (Easiest)**
1. **Open your browser** and go to: `http://localhost:5173`
2. **Login** with your OTP authentication
3. **On the Dashboard**, click the **"View Demo Analysis"** button (green button)
4. **You'll see** the complete Analysis page with dummy data!

### **Method 2: Using New Analysis Page**
1. **Go to** `/new-analysis` page
2. **Click the green "View Demo Analysis"** button at the bottom
3. **You'll be redirected** to the Analysis page with dummy data

### **Method 3: Direct URL (if you have data)**
1. **Go to** `http://localhost:5173/analysis`
2. **If no data**, you'll see a helpful message with options
